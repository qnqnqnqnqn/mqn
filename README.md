# 跳一跳 APP

一个轻量的原生前端小游戏，模拟“跳一跳”玩法：

- 长按/按住画布蓄力。
- 松开后角色会按蓄力强度跳跃。
- 成功落到下一个方块即可加 1 分。
- 掉落或跳出画布则游戏结束。

## 运行方式

### 方式一：一键启动（推荐）

在项目根目录执行：

```bash
./run.sh
```

默认监听 `4173` 端口，打开浏览器访问：

```text
http://127.0.0.1:4173/index.html
```

也可以自定义端口：

```bash
./run.sh 8080
```

### 方式二：直接打开文件

直接在浏览器打开 `index.html` 即可开始游戏。
